# Listik — ТЗ на сборку

Заметки в виде мессенджера: копия Telegram iOS, только каждый «чат» — тема заметок, сообщения пишешь сам себе.
Все экраны утверждены, макеты лежат в `design/01…08-*.html` (открывать в браузере). Делать строго по ним.

## Техника
- Expo SDK 57, TypeScript, React Native 0.86. Образец конфигурации: репо `dilukliu0-cyber/energos` (те же версии пакетов: expo ~57.0.26, react 19.2.3, react-native 0.86.3). Ставить пакеты через `npx expo install`.
- Bundle ID `com.diluk.listik`, имя «Listik», `ios.appleTeamId: "RH67B2MANC"`, `ios.infoPlist.ITSAppUsesNonExemptEncryption: false`, `supportsTablet: false`, `userInterfaceStyle: "automatic"`, iOS 17+ (`expo-build-properties`).
- Только один телефон, без входа и аккаунтов, без синхронизации. Всё хранится локально (SQLite `expo-sqlite` или JSON-файлы; на web — fallback, чтобы работал предпросмотр `npm run web`).
- Фото/файлы/голосовые копировать в папку приложения (`expo-file-system`).
- Навигация: нативный стек с iOS-свайпом назад + нижние вкладки Чаты / Медиа / Настройки.
- Иконки: SF Symbols (`expo-symbols`) на iOS, запасные на web. Системные цвета iOS, светлая и тёмная тема (авто + выбор в настройках). Вибро-отклик (`expo-haptics`) на отправку, закреп, долгое нажатие, свайпы.
- Шрифт системный (логотип тоже).
- Приложение не должно падать целиком: ErrorBoundary с текстом ошибки на экране. Нативные модули (whisper, распознавание речи) грузить лениво в try/catch — если модуль недоступен, показывать ошибку, а не падать.

## Экраны (по макетам)
1. **Список чатов** (`design/01-chats.html`): «Изм.», «Чаты», карандаш (новый чат). Поиск по всем заметкам (включая расшифровки). Строка «Архив» первой. Строка чата: иконка (значок+цвет или своё фото), название, последняя заметка, время; закреплённые чаты сверху со значком скрепки; синий счётчик невыполненных пунктов списков. Свайп влево — архив/удалить, вправо — закрепить. Без папок.
2. **Чат** (`design/02-chat.html`): обои как в ТГ, все заметки справа (зелёные пузыри как в ТГ, тёмная тема — синие), без галочек ✓, разделители дат. Плашка закрепа сверху: несколько закрепов, тап листает и прыгает к сообщению, ☰ — список всех. Типы заметок: текст, ответ на заметку (reply), фото (с подписью), файл, голосовое, список с галочками (сделанное зачёркивается). Свайп заметки влево — ответить. Долгое нажатие: Ответить, Закрепить, Изменить, Копировать, Переслать (в другой чат), Выбрать (мульти-выбор), Удалить. НЕТ «Сделать делом».
3. **Профиль чата** (`design/03-chat-profile.html`): тап по иконке в шапке. Аватар, название, «N заметок · с даты». Кнопки: поиск по чату, обои (свои для этого чата), в архив, ещё (очистить, удалить). «Изм.» — название, значок, цвет, фото. Вкладки: Медиа (сетка по месяцам), Ссылки, Файлы, Голосовые (расшифровка по кнопке →A), Закреп.
4. **Медиа** (вкладка, `design/04-media-newchat.html`): все фото из всех чатов, фильтр-чипсы по чатам, точка цвета чата на фото, по месяцам. Фото на весь экран (`design/08`): «3 из 18», свайпы, свайп вниз закрывает, кнопки поделиться / показать в чате / закрепить / удалить.
5. **Новый чат**: фото или значок, название, 8 цветов, сетка значков; «Отмена»/«Создать».
6. **Настройки** (`design/05-settings.html`): Оформление (Авто/Светлая/Тёмная), Обои чатов (8 узоров + своё фото + однотонный цвет), Размер текста, Расшифровка (подэкран), Вибро-отклик, Архив, Недавно удалённые, Память (сколько занимают медиа, очистка), О приложении. НЕТ экспорта, НЕТ пароля/Face ID.
7. **Недавно удалённые**: заметки и чаты 30 дней, «осталось N дн.», выбрать / восстановить все / удалить все (удаление навсегда с подтверждением). Автоочистка старше 30 дней при запуске.
8. **Первый запуск** (`design/08`): заставка (синий фон, белая иконка-пузырь, «Listik»), пустой список «Создайте первый чат» с чипсами-шаблонами Идеи/Покупки/Фильмы/Работа и кнопкой «Новый чат».
9. **Меню скрепки**: камера + последние фото, Галерея, Файл, Список. («Место» не делать.)
10. **Доступы**: перед системным запросом своё окно-объяснение (микрофон, фото, распознавание речи), только когда доступ впервые нужен; если запрещён — кнопка «Открыть настройки».

## Голосовые и расшифровка — ГЛАВНОЕ, сделать качественно
Макеты `design/06-voice.html`, `design/07-whisper-download.html`.
- Запись: удерживать микрофон; влево — отмена; вверх на 🔒 — фиксация. Плеер с волной и длительностью (`expo-audio`).
- Расшифровка делается в фоне сразу после записи, показывается по кнопке →A (A↑ сворачивает). Расшифровку можно редактировать. Поиск ищет по ней.
- По умолчанию «Обычная» — встроенное распознавание Apple на устройстве (`expo-speech-recognition`, распознавание аудиофайла, ru-RU / авто).
- «Точная · Whisper» — `whisper.rn`, модель `ggml-large-v3-turbo-q5_0.bin` (~547 МБ) с Hugging Face (ggerganov/whisper.cpp). Качается ТОЛЬКО по желанию пользователя, через любую сеть (не только Wi-Fi), с прогрессом, отменой и докачкой в фоне.
- При ПЕРВОЙ расшифровке — шторка один раз: «Хотите точнее? Сейчас работает обычная расшифровка, в ней бывают ошибки. Скачайте точную модель Whisper… 547 МБ · один раз» [Скачать] [Не сейчас].
- Настройки → Расшифровка: выбор Обычная/Точная, статус модели, прогресс загрузки, язык (Авто), «Расшифровывать сразу», удалить модель. После загрузки — можно перерасшифровать старые голосовые.
- Расшифровка Whisper с пунктуацией, язык auto/ru. Отображать прогресс «расшифровываю… 60%».

## Сборка в TestFlight
- Workflow `.github/workflows/testflight.yml` уже в репо (macos-26, Xcode 26.4+, prebuild, archive, upload). Схема берётся по имени workspace.
- Секреты репо: `ASC_KEY_ID`, `ASC_ISSUER_ID`, `ASC_KEY_P8`.
- Номер сборки = 100 + run_number.
- Запуск: `gh workflow run testflight.yml --repo dilukliu0-cyber/listik`. Успех = «Upload succeeded».
- Запись приложения в App Store Connect и группа тестировщиков создаются вручную владельцем.
